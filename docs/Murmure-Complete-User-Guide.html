01 / Requirements

Start with the right Mac and the right file.

Apple Silicon

M1 or newer. The current shared app does not run on Intel Macs.

macOS 26 or later

The modern speech and on-device model APIs require macOS 26+.

Install the shared archive

  1. Download Murmure.app.zip from the GitHub release link your friend shares with you.
  2. Double-click the ZIP, then drag Murmure.app into the Applications folder.
  3. Open Applications. Control-click Murmure, choose Open, then confirm.
  4. If macOS still blocks it, open System Settings > Privacy & Security and choose Open Anyway.
  5. Keep only one installed copy in Applications. Do not run the app from Downloads or an external build folder.

Why the warning? Friend builds may be locally signed but not notarized through Apple's paid distribution service. The warning does not mean Murmure sends your audio anywhere.

Intel compatibility is still a separate hardware investigation. Do not bypass the requirements shown above.

02 / First launch

Complete all eight setup steps.

The Continue button stays unavailable until the required proof for that step is complete.

  1. Display language. Choose English, Français, or Español for Murmure's menus, buttons, and instructions.
  2. Private by design. Review where data lives and the two network exceptions.
  3. Microphone. Request access so Murmure can hear recordings.
  4. Accessibility. Open macOS settings and grant access so the global shortcut and text insertion work.
  5. Shortcut. Choose a physical key and one of the three gestures.
  6. Microphone test. Choose an input, start the meter, speak, and stop the test.
  7. Language you speak. Keep Automatic for multilingual recognition or choose an explicit language hint.
  8. Test dictation. Record a short sentence, finish it, then acknowledge the completed test.

Microphone access

Lets Murmure capture audio. macOS owns this permission.

Accessibility access

Lets the global shortcut work and inserts finished text into the app you were using.

Changed a permission? Quit and reopen Murmure after macOS shows the grant. You can rerun the whole setup later from Settings.

MURMURE06 / 20

05 / Gestures

Choose the physical behavior that fits your desk.

Hold

Press and hold to record. Release to finish. Best for short dictation and the default fn workflow.

Double-tap and hold

Tap once, then press and hold within the short timing window. Release to finish.

Press to start/stop

Press once to begin and press again to finish. Useful when holding a key is uncomfortable.

Hands-free dictation

Open Settings > Shortcuts, enable hands-free, and choose a shortcut that is different from push-to-talk and Command Mode.

Press hands-free key>Speak without holding>Same key or Enter finishes

Finish

Press the same hands-free key or press Enter.

Cancel

Press Escape while the hands-free session is active.

Shortcut safety. Murmure rejects duplicate shortcuts, bare ordinary keys, and common macOS-reserved combinations. Right Option may act as AltGr on international keyboard layouts.

Use Restore shortcut defaults if custom bindings become confusing.

MURMURE07 / 20

06 / Engines

Two local engines with different strengths.

Apple streaming

Text while you speak

  • Runs through Apple's Speech framework.
  • Shows streaming transcript updates.
  • Uses an explicit language hint.
  • The operating system manages language assets.
  • Best when you want immediate feedback.
Parakeet batch

Text after release

  • Runs locally through FluidAudio and Core ML.
  • Transcribes after the recording finishes.
  • Provides Automatic recognition for 25 languages.
  • May download about 470 MB on first use.
  • Best for multilingual automatic recognition.

Compare both local engines

Compare Mode runs both engines on one recording and opens a side-by-side result window. It deliberately does not type either result into the focused app.

Timing caution. Treat the comparison as a quality review, not a universal speed ranking. Engine timing begins after different preparation stages.

07 / Languages

What you see and what you speak are separate.

Language you speak

In Settings > Dictation, Automatic selects Parakeet and recognizes supported languages as you speak. Choose an explicit language only when you want a decoder hint.

Display language

In Settings > Appearance, choose English, Français, or Español for menus, buttons, and instructions. This never changes the language you dictate.

Automatic supports these 25 languages

BulgarianCroatianCzechDanishDutchEnglishEstonianFinnishFrenchGermanGreekHungarianItalianLatvianLithuanianMaltesePolishPortugueseRomanianRussianSlovakSlovenianSpanishSwedishUkrainian

Cleanup behavior

English, Spanish, and French have language-specific deterministic cleanup. Other explicit languages and Automatic use neutral cleanup, so English assumptions are never applied to another language.

Smart cleanup limitation. Apple's on-device AI cleanup is unavailable while Language you speak is Automatic. Choose explicit English, Spanish, or French if you want that optional feature.

Follows the current macOS input without changing macOS. This is the safest choice if you regularly switch between built-in, USB, Bluetooth, or display microphones.

MURMURE10 / 20

09 / Cleanup

Speech becomes usable text in a deliberate order.

Raw transcript>Deterministic cleanup>Optional smart cleanup>Snippet>Dictionary correction

Clean up transcripts

Removes common fillers, handles spoken punctuation, normalizes text, and improves sentence structure using local deterministic rules.

Smart cleanup

Uses Apple's on-device model for optional AI cleanup. It has no network fallback and is available only when the device, OS, model, and explicit language are supported.

What cleanup does not do

  • It does not upload audio or transcripts.
  • It does not replace the explicit correction and dictionary workflow.
  • It does not use English-specific assumptions in Automatic mode.
  • It does not change snippet matching: a snippet still requires a complete matching utterance.

Turn it off when exact raw wording matters. Disable Clean up transcripts before legal quoting, code-like strings, or other situations where every recognized token should remain untouched.

10 / Command Mode

Edit selected text without sending it to a server.

  1. Select editable text in another app. The selection cannot be empty.
  2. Hold ⌃ ⌥ ⌘ D.
  3. Speak an instruction such as "make this shorter" or "translate this into French."
  4. Release the shortcut. Murmure creates a proposal with Apple's on-device model.
  5. Review and edit the proposal. Choose Replace selected text, Copy proposal, or Cancel.
COMMAND MODELocal transformation

Original

The exact selected text remains visible here.

Proposal

The proposed replacement stays editable until you choose what to do.

CancelCopy proposalReplace selected text

Safety rule. Murmure replaces text only if the current selection still exactly matches the original captured selection. If it changed or the target is no longer writable, replacement is refused and Copy proposal remains available.

Command Mode requires Apple's on-device Foundation Model. Settings explains when the model is unavailable. Selected text and spoken instructions are not added to Murmure history.

Use “Voice add”

Say “Voice add,” followed by the complete trigger, such as “Voice add, my address.” You may continue speaking after it; Murmure inserts the snippet and keeps the rest of your sentence. Saying only the exact trigger still works.

Multiline replacements

Line breaks are preserved in the inserted text.

Before dictionary rules

Snippet expansion happens before dictionary correction.

Manage snippets from the main Snippets destination

  • Add creates a trigger, replacement, and enabled state.
  • Toggle temporarily disables a snippet without deleting it.
  • Edit changes the trigger or replacement.
  • Delete removes the snippet after confirmation.

Validation. Triggers and replacements cannot be empty. Duplicate normalized triggers are rejected so two snippets never compete for the same phrase.

12 / Dictionary

Teach the terms and corrections that matter to you.

Term

Add a name, product, place, or phrase that exists in your vocabulary. Terms can help bias speech recognition and preserve preferred spelling.

Correction

Define what Murmure commonly hears and what it should write instead. Example: cloud code > Claude Code.

AnthropicTermEditPauseTrash
cloud code > Claude CodeCorrectionEditPauseTrash

Dictionary controls

  • Search terms and corrections from the top of the Dictionary page.
  • Add a new entry with Command-N or Add entry.
  • Edit, disable, enable, or delete any row.
  • Reveal the plain-text dictionary file from the footer when advanced manual inspection is needed.

Prefer specific corrections. Murmure warns when a trigger looks like an ordinary common word because broad replacements can change text you did not intend to change.

Rule to remember: "cloud code" > "Claude Code"

Complete correction workflow

  1. On a Home history row, choose the pencil Correct action.
  2. Optionally play the original recording.
  3. Edit I meant, or choose Dictate to fill the draft with a fresh voice recording.
  4. Review the suggested rule. Leave Remember on only when the rule is safe.
  5. Choose Save correction. This is the only action that changes history or the dictionary.

Punctuation-only changes, insertions, deletions, or ambiguous edits may be saved to history without creating a dictionary rule. If the data drive is unavailable, a safe rule can remain pending and retry later.

15 / Storage and privacy

Your working data stays in the local loop.

LOCAL DATA
Model downloadUpdate check

Stored locally

Settings, snippets, dictionary entries, transcript history, captured audio, and Command Mode processing remain on the Mac or configured data drive.

Network exceptions

Only one-time local model downloads and optional update checks use the network. There is no cloud transcription or Command Mode fallback.

Data storage card

Settings > Privacy & storage shows the exact active storage location and whether it is ready. Most Macs use Application Support automatically. A specially configured operator Mac may use its named external drive. Use Reveal Murmure data folder to inspect the active location.

Diagnostics are sanitized. Preview, copy, or export configuration and permission facts. Reports exclude dictated text, history, audio, snippets, dictionary data, and local paths.

MURMURE18 / 20

15 / Updates and support

Update safely. Diagnose without exposing your words.

Check for updates

  1. Open Settings > Advanced & updates.
  2. Choose Check for updates. Murmure checks GitHub Releases and stages a verified archive locally.
  3. When a newer version is ready and no recording is active, choose Install and relaunch.
  4. After relaunch, confirm the version number shown in Settings.

Common problems

Shortcut does nothing
Confirm Accessibility is Granted. Quit and reopen Murmure after changing the macOS permission.
No audio level
Confirm Microphone is Granted, select System default, then run Test microphone.
No text inserted
Keep an editable field focused. Turn off Compare Mode, which intentionally does not insert text.
Automatic unavailable
Select Parakeet and allow its one-time local model download to finish.
Smart cleanup disabled
Turn on cleanup and choose explicit English, Spanish, or French. Automatic is not supported.
Command Mode unavailable
Check the availability message in Settings. Apple's on-device model is required.
Storage not ready
Reconnect the configured drive if one is used. Do not delete or move the active data folder by hand.
