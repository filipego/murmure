# Murmure Quick Guide

This eight-slide guide introduces Murmure 0.1.14 to friends and collaborators. It covers compatibility, setup, everyday dictation, automatic multilingual recognition, Command Mode, personalization, privacy, and quick troubleshooting.

- [View the presentation in Canva](https://www.canva.com/d/StWgAK3p0Hg2lUz)
- [Download the PDF](../output/pdf/Murmure-Quick-Guide.pdf)
- [Open the editable HTML slide source](Murmure-Quick-Guide.html)

The current shared build requires Apple Silicon and macOS 26 or later. An Intel edition is not yet available.
